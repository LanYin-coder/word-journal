# 拾词 · Word Journal

一个在 Mac 本地运行的简洁英汉词汇 WebUI。Python 3.10+，不需要安装第三方依赖。

## 首次从 GitHub 使用

```sh
git clone https://github.com/LanYin-coder/word-journal.git
cd word-journal
python3 server.py --port 8791
```

仓库不包含个人词汇、学习记录、备份或完整 ECDICT 数据。首次运行会新建本地数据库；可直接导入带中文释义的词表。仅输入英文自动补全需要先安装 ECDICT：从下文词库原项目下载 `ecdict.csv` 到 `data/`，执行 `python3 server.py --dictionary data/ecdict.csv`，再启动服务。

## 打开

双击 `启动拾词.command`。也可在本目录运行：

```sh
python3 server.py --port 8791
```

浏览器打开 http://127.0.0.1:8791。终端服务需要保持运行，按 Control+C 停止。界面与本地词典离线可用；词典发音录音需要网络，无法加载时使用系统朗读。

## 使用

- 导入新词：粘贴词表或上传 UTF-8 TXT / CSV / TSV，每行一个词；预览后确认导入。
- 纯英文如 `seek`：使用本地 ECDICT 自动补全；未收录时提示补充释义，不会编造翻译。
- 手工释义如 `seek v.查找，寻找`，英文后须有空格。支持合并词性 `record v&n.记录`、`adj&adv.`（保留原写法），也支持 `take off phr.起飞；脱下`、`reluctant adj.不情愿的`。CSV 支持英文与中文两列，含逗号的字段按标准 CSV 加引号。导入内容不要包含标题行。
- 在「词汇背诵」页切换「遮蔽中文」「遮蔽英文」「中英对照」，点击遮蔽区域显示答案，再选择「记住了」或「再记一次」。每个方向分别记录当天的最后一次评分。
- 在「词汇背诵」页的「历史记录」中选择某一天，或使用日期选择器复习历史词汇。复习旧词也计入今天的学习记录。日期按浏览器本地日历。
- 搜索「我的词汇」支持英文或中文释义，显示首次记录日期、记录距今几天、实际学习天数与上次学习日期。同一天两个方向复习仍只计一个学习日。
- 切换到「ECDICT 本地词典」，按英文完整词或前缀查询；显示是否已经记录，可选择「加入今日新记」。
- 相同英文不重复建词；可同时出现在不同日期。重复导入保留原释义，不覆盖个人数据。
- 导出 JSON 备份、恢复备份（合并）。备份包含个人词汇、日期记录和学习进度，不包含公共词典。

## 听写与默写

在主页点击「听写与默写」按钮，跳转到练习设置页面，选择记录日期和出题方式，再点击「开始练习」进入独立的答题页面：

- 英文提示：看英文，输入中文释义，查看参考答案后自评。
- 中文提示：看中文，输入英文，自动比对拼写（忽略大小写和首尾空格）。
- 中英混合：两种提示按 1:1 分配，每词一题、随机排列；奇数题时最多相差一题。
- 英文听写：点击播放按钮，可反复听英文并输入拼写。使用浏览器语音合成及系统英文语音；朗读不可用时会提示。

按 Enter 提交答案。「记住了」或「再记一次」会保存为今天的学习记录，再进入下一题；练习历史日期的词汇也记录到今天。中文同义表达可自行判定掌握情况，英文自动比对结果仅供对照。每成功默写或跳过 10 词完成一轮，并播放礼花（系统减少动态效果时仅显示完成提示）。错词不计成功，插入下一轮开头，其他词顺延；尾轮不足 10 词时先完成其余词，再补练错词，直到全部掌握。点击「上一词」回退本轮计数并重新作答，不会重复累计；重新评分会更新今天同一词与题型的学习结果。「跳过」按已掌握保存。同一浏览器标签页中，刷新答题页会继续本轮进度（当前题重新作答）；已保存的学习记录不会丢失。

右上角可切换浅色 / 黑色主题，浏览器自动记住选择。

## 数据与词典

个人数据和公共词典存储在本目录 `data/journal.sqlite3`。关闭网页或重启服务不会丢失。清理浏览器缓存不会删除词汇。迁移时导出备份，或在停止服务后复制整个文件夹。请勿删除数据库。

词库来自 [skywind3000/ECDICT](https://github.com/skywind3000/ECDICT)，MIT 许可，原文保留在 `data/ECDICT-LICENSE`，项目说明在 `data/ECDICT-README.md`。这是社区开源词库，并非出版社官方词典。当前安装使用项目 `ecdict.csv` 中有中文释义的词条。

重新安装词典可从原项目下载 `ecdict.csv` 后运行（只更新公共词典，保留个人记录）：

```sh
python3 server.py --dictionary data/ecdict.csv
```

```sh
python3 -m unittest discover -p test_app.py -v
```

`ui-test.cjs` 为开发时使用的 Playwright 浏览器流程测试，需要可用的 Playwright 和 Chrome，测试服务使用独立数据库，避免污染个人记录。

## 页面导航

主页 `/` 仅展示功能入口和词数，背诵词表在 `/review`。通过入口按钮跳转：词汇与词典 `/vocabulary`、导入新词 `/import`、练习设置 `/practice`。开始练习进入专注答题页 `/practice/session`，设置与答题分开显示。支持直接打开页面链接、刷新、浏览器前进后退。没有进行中的练习时，直接打开答题链接会返回练习设置。

练习调度测试：`node test-practice-engine.cjs`。浏览器流程测试 `ui-turns-test.cjs` 使用模拟词汇与 API 响应，不修改个人数据库。

## 词数选择、每日计划与休息

点击开始后弹出词数轮盘，支持鼠标滚轮、触摸滑动、点击数字、方向键与 PageUp / PageDown。确认后随机选取指定数量的词，进入答题页；混合模式仍按选中词数均分题型。

练习设置页提供「今日词汇两遍、昨日词汇一遍」的建议计划，按每次选择的词数练习；每次完成计一遍。完成后自动弹出「恭喜记忆完成！」，同时开始 5 分钟休息。可关闭窗口，右下角保留计时入口。到时弹出继续学习提示，优先建议今日第二遍，再建议昨日复习。没有昨日记录时会提示无词汇，可自行改选日期。

休息结束时间、每日计划进度保存在此浏览器的本地存储，刷新可恢复；计时按实际时间计算，后台返回时会校正。清理浏览器数据会清除计划和计时，但不会删除 SQLite 中的词汇与学习记录。页面关闭时不会发送系统通知，重新打开后恢复提示。

## 默写快捷键

- Shift+Enter：跳过当前词，直接计为已掌握和本轮成功，不加入错词补练。
- Tab：返回上一词并回退本轮计数。Shift+Tab 保留反向焦点移动。
- Enter：未提交时查看答案；已提交时进入下一词。英文拼错时自动按需补练保存，英文正确或中文自评默认按掌握保存。
- ～ / ~ / 反引号键：标记「再记一次」；空答案会立即重记并安排下轮补练，非空答案排入后续补练。

快捷键仅在独立答题页生效；输入法选词、组合键、上浮窗口与保存中不会触发练习操作。长按不会连续跳题。

### 空答案的立即重记

空着答案点击「再记一次」或按 ～：当前词立即保留重记，同时只安排一份下一轮补练，不推进题目、不计成功。页面显示可收起的参考答案。立即重记完成后才进入下一词，这次即使答对也不计本轮成功；下轮正式答对或跳过时再计掌握。重复按重记不会产生多份补练。已有非空答案时的「再记一次」仍按错词排入后续轮次。状态支持刷新恢复及「上一词」回退。

## 主导航与每日记词

页面顶部的主导航栏提供：首页、每日记词、词汇背诵、听写默写、导入新词、词汇与词典。当前页面高亮；链接支持浏览器前进后退与新标签页打开。

「每日记词」地址 `/daily`，只浏览每天记录过的词汇，不自动生成学习记录。可用日期输入框、有记录的日期列表、今天 / 昨天按钮筛选；提供中英对照、遮蔽中文、遮蔽英文三种显示方式。点击遮蔽区域可单独揭晓；更换日期或显示方式时重新遮蔽。显示偏好保存在当前浏览器，日期保存在链接参数中，例如 `/daily?date=2026-11-02`，刷新后保持筛选。没有词汇的日期显示空状态。

### 局域网访问

服务默认监听 `0.0.0.0`，同一局域网的设备可访问 `http://Mac的局域网IP:8791`。Mac 上仍可使用 `http://127.0.0.1:8791`。在 Mac 终端运行 `ipconfig getifaddr en0` 可查看 Wi-Fi 地址；网络变化后地址可能改变。手机热点连接时，手机也使用 Mac 的这个地址。Mac 需要保持开机并运行服务，如有防火墙提示请允许 Python 的传入连接。

所有设备使用 Mac 上同一份词汇与学习记录，目前没有账户和访问密码，同一网络的设备都可查看和修改。只允许本机访问时，运行 `python3 server.py --host 127.0.0.1 --port 8791`。

发音优先使用 Free Dictionary API 提供的词典录音；若中转地址失效，服务会尝试获取其标注的 Wikimedia Commons 原始录音。成功获取的录音缓存于 `data/audio/`，由 Mac 服务统一提供给电脑和手机，缓存不会上传 GitHub。录音旁显示原始来源与许可。首次获取需要联网，缓存后可重复播放；没有可用录音时使用系统朗读。
